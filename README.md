# AtomAssistant 原子助手

7×24 常驻云端、事件驱动、带持久化记忆的个人智能体运行时，由用户自部署在自己的服务器上。

## 功能

### 任务与调度

- **持久化任务内核**：任务按步骤记录日志，进程崩溃后可恢复并幂等重放；每个任务有预算硬上限。
- **事件唤醒**：任务可以订阅事件（如 `topic == "mail.received" AND payload.from CONTAINS "张总"`），事件命中时被唤醒。
- **定时任务**：到点创建任务；停机期间不补跑，上一次未结束时不叠加。
- **Webhook**：外部系统凭令牌向事件总线投递事件，投递的内容一律按外部内容对待。
- **事项清单与会话**：用户交代的事记入事项清单，多次补充接在同一件事上；对话按天归入会话并生成摘要。

### 记忆

- **分层记忆**：任务结束后提炼用户的偏好、习惯和做事流程；偏好带适用场景，写入时必须判定时效。
- **来源决定权重**：用户明确陈述的信息直接生效；模型推断的信息以较低权重保存，经其他任务交叉印证后提高。
- **冲突与安全**：冲突的记忆不被覆盖，旧值进入版本链；过敏、忌口等安全信息每次强制注入上下文。
- **需要核实的三种情况**：与已有记忆冲突、涉及安全的推断、读过邮件或网页后提炼的内容。
- **向量召回**：可选，记忆编码成向量存入本机的 Qdrant。
- **表达风格**：从用户亲手写的话和已发送的邮件中学习说话方式，用于答复和代写。

### 模型

- **两种接口协议**：OpenAI 兼容与 Anthropic 兼容，按用途路由。
- **多模型协作**：需要规划的事由任务模型出方案并执行，主模型评估方案、审核结果；短程的事由主模型直接办。
- **按评分派活**：用户对结果的评分按任务类别记在模型名下，同类任务优先交给评分高的模型。
- **图片与视频**：原件随上下文交给支持对应输入的模型，不先转成文字。
- **联网搜索与读网页**：使用模型服务自带的联网搜索；配置 DeepSeek 时另接其搜索与抓取接口。

### 工具与数据源

- **MCP 网关**：接入远程或本机的 MCP server，逐个工具设定副作用等级和参数隐私上限；预置高德地图、滴滴出行、飞常准、12306。
- **Skill**：安装他人写好的流程（`skill.yaml`），安装前必须通过 SkillSpector 扫描，执行时只能使用它声明且用户授权的工具。
- **能力自装**：缺少工具时到 skills.sh 和 MCP 官方登记处查找，扫描通过且低风险的直接安装，有外传风险的由用户审批。
- **日历与邮件**：CalDAV 查改日程，IMAP 读信与整理，SMTP 发信；另有节假日与调休查询、和风天气。
- **文件处理**：在本机读写 Word、Excel、PowerPoint，读 PDF 与文本；助手只能访问工作区目录，覆盖前留底。
- **代码沙箱**：在隔离环境里运行 Python，处理工作区里的文件。
- **文件下载链接**：为助手生成的文件创建最长 24 小时的临时下载链接。
- **付款**：支付宝 Agent 支付，支持收银台付款和按次收费的资源（HTTP 402）；每一笔都需用户在支付宝里授权。

### 消息渠道

- **四个渠道**：QQ、微信、飞书、钉钉，均为单聊，由助手主动连出，服务器不需要开放入站端口。
- **收发多种消息**：文字、图片、文件、语音、视频；格式转换由随程序发布的 ffmpeg 完成。
- **语音转文字**：语音消息由本机的离线识别服务转成文字后处理。
- **主人名单**：只有列入 `owners` 的账号发来的话才会变成任务。
- **手机 App 数据源**：手机采集健康、位置等接口取不到的数据，凭设备令牌上报。

### 管理后台

- **网页后台**：查看和创建任务、审批动作、管理记忆、模型、消息源、数据源、MCP、Skill、系统提示词、文件和日志。
- **在线查看文件**：在浏览器里打开工作区中的 Word、Excel、PPT 和 PDF。
- **登录**：密码加 TOTP 动态验证码，或通行密钥；默认只监听本机，经 SSH 隧道访问。
- **配置即时生效**：后台保存的配置在进程内重新载入，不需要重启服务。

### 安全

- **自主程度分级**：取数据和新写入直接执行，修改和删除由主模型把关，对外发送由用户确认；可切换为每步确认。
- **信任围栏**：邮件、网页、文件、工具返回的内容进入上下文时只作为材料，不具备指令资格。
- **隐私分级与出口管控**：绝密数据不以明文传给任何工具；模型拼出的出站请求含个人敏感信息时在代码层拦截。
- **保险库**：密钥和证件号等只进不出，模型和日志只见句柄，值在工具调用时由网关换入。
- **落库加密**：数据库内容列写入前加密，数据密钥与本机硬件绑定；工作区文件可选加密。
- **迁移**：`atomctl export` / `import` 按板块导出导入，文件以用户设定的口令加密。

## 运行

```bash
docker compose up -d
export ATOM_DSN='postgres://postgres:atom@127.0.0.1:55432/atomassistant'

go run ./cmd/atomd -migrate-only     # 建表
go run ./cmd/atomd                   # 未设置 ATOM_CONFIG 时为 demo 模式，不产生真实副作用

go run ./cmd/atomctl create "演示任务" "跑通内核"
go run ./cmd/atomctl list
```

接入真实模型与工具：

```bash
cp config.example.yaml config.yaml   # 按注释填写
export ATOM_CONFIG=./config.yaml
go run ./cmd/atomd -check            # 只校验配置与连接
go run ./cmd/atomd
```

配置项的说明见 `config.example.yaml` 中的注释。

## 部署

```bash
cp deploy/deploy.env.example deploy/deploy.env   # 填写服务器地址和 SSH 私钥路径
deploy/deploy.sh setup     # 首次：安装 PostgreSQL、建目录和 systemd 服务、上传程序
deploy/deploy.sh passwd    # 设置后台口令并启动
deploy/deploy.sh tunnel    # 打开 SSH 隧道后访问 http://localhost:8780
deploy/deploy.sh           # 更新：编译、上传、切换；新版本未通过健康检查时自动退回
```

可选组件用 `deploy/deploy.sh sandbox | asr | vector | ip2region | scanner` 安装，用法见脚本开头的注释。

## 测试

```bash
go test ./...
```

Postgres 契约测试默认跳过。运行它需要设置 `ATOM_TEST_DSN` 并加 `-p 1`；该测试会清空目标库，不要指向生产数据库。
